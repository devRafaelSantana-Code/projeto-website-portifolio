## 📌 Sobre o Projeto

O **Personal Website Portfolio** é um projeto de desenvolvimento front-end criado para apresentar minha trajetória acadêmica, minhas competências técnicas e meus projetos desenvolvidos na área de tecnologia.

Desenvolvido com base nos desafios da plataforma **Sujeito Programador**, o website funciona como uma vitrine profissional, centralizando informações sobre minha formação em **Engenharia da Computação**, meus conhecimentos em desenvolvimento de software e meu portfólio de aplicações.

A interface foi estruturada em uma única página, com navegação por âncoras e transições suaves entre as seções, proporcionando uma experiência de navegação simples, intuitiva e organizada.

O projeto também explora a construção de layouts modernos, organização visual de conteúdos, hierarquia tipográfica e apresentação de projetos por meio de uma galeria de trabalhos.

---

## 🚀 Estrutura e Seções

O website é organizado em quatro seções principais, integradas por uma barra de navegação.

### 1. Header e Navegação

Cabeçalho responsável pela identificação do website e navegação entre as seções.

- Menu de navegação.
- Links internos direcionados por âncoras.
- Navegação entre as áreas do portfólio.
- Estrutura adaptável a diferentes tamanhos de tela.

### 2. Home — `#home`

Seção inicial de apresentação, desenvolvida para receber o visitante e direcioná-lo aos principais conteúdos do portfólio.

- Mensagem de boas-vindas.
- Apresentação pessoal.
- Botão de chamada para ação (Call-to-Action).
- Direcionamento para a galeria de projetos.

### 3. Sobre — `#sobre`

Área destinada à apresentação da trajetória acadêmica e dos objetivos profissionais.

- Resumo profissional.
- Formação em Engenharia da Computação.
- Apresentação das competências e conhecimentos técnicos.
- Informações sobre a jornada de aprendizagem em desenvolvimento de software.

### 4. Projetos — `#projetos`

Galeria dedicada à apresentação dos projetos desenvolvidos, organizada em uma estrutura visual de cartões.

- Exibição de capturas de tela das aplicações.
- Organização dos trabalhos em uma grade.
- Apresentação visual dos projetos.
- Botão de contato ao final da seção.

---

## 🎯 Funcionalidades

- **Navegação por âncoras:** acesso direto às seções do website.
- **Rolagem suave:** transições entre as áreas da página.
- **Apresentação pessoal:** seção dedicada à trajetória acadêmica e profissional.
- **Galeria de projetos:** organização visual das aplicações desenvolvidas.
- **Botões interativos:** elementos de navegação e chamadas para ação.
- **Tipografia personalizada:** utilização da família Roboto por meio do Google Fonts.
- **Layout responsivo:** adaptação da interface para diferentes dimensões de tela.
- **Navegação em página única:** apresentação das informações em uma única página HTML.

## 💻 Como Executar

### Pré-requisitos

- Navegador atualizado.
- Git instalado.
- Visual Studio Code (opcional).

### 1. Clonar o Repositório

```bash
git clone URL-DO-REPOSITORIO.git
```

### 2. Acessar a Pasta do Projeto

```bash
cd projeto-website-portfolio
```

### 3. Executar a Aplicação

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** no Visual Studio Code para visualizar as alterações em tempo real.

Por se tratar de um projeto front-end estático, não é necessário instalar dependências ou configurar um servidor backend.

## 🧠 Aprendizados

O desenvolvimento do Personal Website Portfolio proporcionou a aplicação prática de conceitos fundamentais da construção de interfaces web, com foco na organização de informações e apresentação visual de projetos.

- **HTML5:** estruturação semântica e organização do conteúdo em seções.
- **CSS3:** estilização de componentes, posicionamento e transições visuais.
- **Flexbox:** construção de layouts flexíveis e alinhamento de elementos.
- **CSS Grid:** organização de galerias e distribuição de conteúdos em grade.
- **Google Fonts:** integração de tipografia externa para aprimorar a identidade visual.
- **Navegação interna:** utilização de âncoras para estruturar a experiência de navegação.
- **Design responsivo:** adaptação da interface a diferentes dimensões de tela.
- **Portfólio profissional:** organização e apresentação de projetos e informações acadêmicas.

O projeto contribuiu para consolidar conhecimentos em HTML5 e CSS3, além de desenvolver a capacidade de transformar requisitos visuais em uma interface organizada, funcional e direcionada à apresentação profissional.
